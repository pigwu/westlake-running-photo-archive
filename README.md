# 拾光 · 跑团照片档案

**GitHub Pages + 学校网盘版本已经可用：** 按 [GitHub 发布操作说明](GITHUB_PAGES.md) 发布，无需自建服务器。网页按日期和活动组织相册，访问者输入分享密码后直接读取网盘照片，支持本机人脸分组。运行 `npm run build:pages` 构建此版本。下文说明保留的服务器版本。

面向西湖跑团的照片存档网页，React + Vite 前端、Node.js + Express API、SQLite 索引。原图保存在本机、可访问的网盘同步目录或挂载的 NAS/SMB 目录；缩略图、活动、标签及成员分组保存在服务器的 `data/` 目录。

## 本机体验

需要 Node.js 22.13 或更新版本（推荐 Node 24 LTS）。SQLite 使用 Node 内置模块，无需额外数据库服务。

```powershell
cd D:\跑团公用平台
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。初始照片均标为示例，来自 Unsplash；上传真实照片后自动切换到真实档案。人脸模型已放在 `public/models/`，分析时无需调用第三方服务。重新获取示例图片与模型可运行 `node scripts/prepare-assets.mjs`。

## 功能

- 批量上传 JPG、PNG、WebP，单张最大 25 MB，每次选择最多 100 张，前端分批发送。
- 保存未经修改的原图，生成经过旋转校正的缩略图；SHA-256 内容去重。
- 按活动、日期、月份、标签、成员筛选；网格和时间线视图。
- 新建/编辑活动；批量更改活动、日期、标签；全局精选收藏。
- 回收站只隐藏索引记录，保留原文件，可恢复。
- 本机浏览器检测人脸并按相似度分组，可命名与合并成员；CPU 模式兼容无 GPU 的校内电脑。
- 配置同步目录，扫描并导入已有图片，不移动原文件；识别 `YYYY-MM-DD_活动名称` 文件夹。
- 管理员及只读跑友两种访问口令；只读用户可浏览、搜索、下载，无法修改档案和访问回收站。

## 学校网盘与校内网页

详见 [校内部署说明](DEPLOYMENT.md)。附件 Windows 手册说明了客户端同步、文档库和细粒度权限，但没有开放 API、WebDAV、服务账号或常驻服务器同步的技术说明。不能仅凭网页版地址声称 API 已连接。

学校客户端在资源管理器中显示的目录可能属于虚拟命名空间。只有 Node.js 能直接读取和写入的实际文件系统路径，才能使用本项目的目录适配方式；不能把客户端内部缓存文件夹当作照片目录。若客户端不提供可访问的同步路径，应由学校 IT 提供 NAS/SMB 挂载、正式开放 API，或采用人工下载/上传中转。

项目当前不会登录学校门户，不保存学校账号密码，也不自动模拟客户端操作。是否已同步到云端以 WestlakeDrive 客户端显示为准。

## 运行生产版

```powershell
Copy-Item .env.example .env
# 根据部署说明编辑 .env
npm run build
npm start
```

生产版由同一个服务同时提供网页、图片与 API，默认 http://127.0.0.1:3001 。开发时前端代理到 3001；无需跨域配置。环境变量：

| 变量            | 用途                                                    | 默认值              |
| --------------- | ------------------------------------------------------- | ------------------- |
| `PHOTO_ROOT`    | 原图目录；设置后优先于网页设置                          | `data/originals`    |
| `DATA_DIR`      | SQLite、缩略图目录                                      | `data`              |
| `PORT`          | 网页/API 端口                                           | `3001`              |
| `HOST`          | 监听地址                                                | `127.0.0.1`         |
| `ARCHIVE_TOKEN` | 管理员口令                                              | 本机模式可不设      |
| `VIEWER_TOKEN`  | 跑友只读口令，须与管理员口令不同                        | 不启用只读入口      |
| `COOKIE_SECURE` | HTTPS 反向代理下设为 `1`，使登录 Cookie 仅经 HTTPS 发送 | 直连 HTTPS 自动启用 |

对非 localhost 地址开放时必须设置管理员口令。校内正式运行还应配置只读口令，通过学校反向代理提供 HTTPS，并限制访问范围到校内/VPN；不要把开发用的 Vite 服务对外开放。

更换原图目录只影响后续上传，旧照片仍引用原位置。修改活动/日期只修改索引，不重排原文件。原图路径会按 `年份/YYYY-MM-DD_活动名/随机ID.jpg` 创建，原文件名保存在索引中并用于下载。

## API

除登录外，有访问口令时均需 `Authorization: Bearer <口令>` 或登录后取得的 HttpOnly Cookie。学校网盘凭证不应发送到这些接口。

| 接口                            | 用途                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------- |
| `POST /api/login`               | `{ "token": "访问口令" }`                                                                   |
| `POST /api/logout`              | 清除会话 Cookie                                                                             |
| `GET /api/status`               | 存储可访问性、统计、角色；仅管理员能查看实际目录                                            |
| `GET /api/photos`               | 照片元数据；只读角色自动隐藏回收站                                                          |
| `POST /api/photos`              | multipart：`photos`（单次最多 10 张）、可选 `date` / `eventId`                              |
| `PATCH /api/photos`             | `{ "ids": ["id"], "changes": { "date": "2026-10-08", "tags": ["合影"] } }`，单次最多 500 张 |
| `GET /api/photos/:id/file`      | 原图                                                                                        |
| `GET /api/photos/:id/thumbnail` | 缩略图                                                                                      |
| `GET /api/photos/:id/download`  | 使用原文件名下载                                                                            |
| `GET /api/events`               | 活动列表                                                                                    |
| `POST /api/events`              | `{ "title": "晨跑", "date": "2026-10-08", "location": "校园" }`                             |
| `PATCH /api/events/:id`         | 更新活动信息                                                                                |
| `PATCH /api/settings`           | `{ "root": "D:/WestlakeDrive/跑团照片" }`，不能覆盖环境变量                                 |
| `POST /api/scan`                | 索引当前原图目录，单次最多扫描 10000 张；跳过符号链接                                       |
| `GET /api/people`               | 成员分组与照片数量                                                                          |
| `PATCH /api/people/:id`         | `{ "name": "成员名" }`                                                                      |
| `POST /api/people/merge`        | `{ "from": "分组ID", "to": "分组ID" }`                                                      |
| `POST /api/faces`               | 保存浏览器生成的 128 维描述向量、人脸框及头像                                               |

所有修改类 API 都要求管理员权限。未创建用户账号体系；口令角色是整个跑团的共享权限。

## 检查与限制

```powershell
npm test
npm run build
```

集成测试使用独立临时目录，验证鉴权和只读隔离、上传、原图完整性、内容去重、标签、回收/恢复、导入、人脸分组合并和重启后的持久化。

人脸分组是相似度聚类，不会自动知道姓名；结果需要人工确认。遮挡、背面、小人脸和模糊照片可能无结果。计算在浏览器进行，首次需加载约 6 MB 本地模型，大批照片应分批分析，并保持页面打开。描述向量和头像存储在服务器索引中，备份与访问权限应与原图同等管理。

当前支持 JPG/PNG/WebP；HEIC、RAW 和视频需要转换或后续扩展。尚未包含学校单点登录、后台自动监听、定时同步、成员独立账号、多人实时推送及浏览器大批量 ZIP 下载。目录扫描是手动触发；网盘客户端云端同步与本系统索引是两个独立过程。

备份需同时包括 `PHOTO_ROOT` 原图和 `DATA_DIR` 索引/缩略图。SQLite 在线备份应使用 SQLite backup 或停服后复制 `archive.sqlite`，不能只复制数据库主文件而忽略正在写入的 WAL。
